## 📚 Sobre o Projeto
O **DELKV** é uma plataforma desenvolvida para modernizar, automatizar e centralizar o controle de acervos bibliográficos. O sistema visa otimizar a rotina operacional de bibliotecas, oferecendo uma interface intuitiva para o gerenciamento interno de livros, controle rigoroso de empréstimos e devoluções, além de um sistema dinâmico de reservas. Com foco em organização e eficiência, o DELKV transforma a gestão do conhecimento em um processo ágil tanto para os administradores quanto para os leitores.

## 🎯 Objetivo
O projeto **DELKV** tem como objetivo principal modernizar e automatizar a gestão do acervo de uma biblioteca, centralizando as operações diárias e otimizando os processos internos através das seguintes funcionalidades:

- **Gerenciar o acervo de livros:** Cadastro, atualização e controle interno de títulos, autores e exemplares disponíveis.
- **Realizar empréstimos e devoluções:** Registro ágil e monitoramento de datas de entrega para evitar atrasos.
- **Efetuar reservas:** Permissão para que usuários reservem títulos que estão indisponíveis no momento.
- **Organização interna:** Controle de fluxo de usuários, penalidades (multas) e relatórios de movimentação do acervo.
  
## 👥 Público-Alvo
O sistema foi desenvolvido para atender tanto a equipe que administra o espaço quanto a comunidade leitora:

- **Bibliotecários e Administradores:** Responsáveis pelo cadastro de livros, relatórios e controle de circulação.
- **Atendentes:** Operadores do sistema no balcão de empréstimos, devoluções e reservas.
- **Leitores (Alunos, Professores ou Comunidade):** Usuários finais que consultam a disponibilidade de obras e efetuam reservas.
  
## 🛠 Tecnologias Utilizadas
A arquitetura do sistema foi desenhada para garantir estabilidade, segurança nos dados e facilidade de manutenção:

- **Linguagens:** Python e PHP
- **Backend & Administração:** Flask (Python) e phpMyAdmin (para gestão visual das tabelas de dados)
- **Frontend:** HTML5, CSS3 e JavaScript
- **Banco de Dados:** PostgreSQL (armazenamento seguro de usuários, livros, empréstimos e reservas)
- **Versionamento:** Git + GitHub
